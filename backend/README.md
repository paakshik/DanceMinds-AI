# DanceMinds AI - Python ML backend

This service adds a **dance-style classifier** to DanceMinds. Given a song title or
raw audio features (and optionally an uploaded audio file), it returns the most
suitable dance form together with a confidence score and a top-k ranking.

## Architecture

```
backend/
├── app.py                 # FastAPI application (REST API + OpenAPI docs)
├── config.py              # Paths and training hyper-parameters
├── dance_styles.py        # 53 supported dance styles + musical priors
├── schemas.py             # Pydantic request/response models
├── services/
│   ├── predictor.py       # Inference, song lookup, fallbacks
│   └── audio_features.py  # Feature extraction from audio (ffmpeg + numpy/scipy)
├── training/
│   ├── build_dataset.py   # Generate the seeded training corpus
│   └── train.py           # Train + evaluate + persist the model
├── data/song_corpus.csv   # Training corpus (regenerated by build_dataset.py)
├── models/                # Trained model + metadata (committed for quick start)
└── tests/
```

Model: a `scikit-learn` `RandomForestClassifier` trained on musical features
(tempo, energy, valence, danceability, acousticness, speechiness,
instrumentalness, liveness, loudness, mode, key, time signature, genre).
Current offline evaluation (53 classes, 2,385 samples):

- top-1 accuracy ≈ **0.58**
- top-3 accuracy ≈ **0.87**

## Quick start

```bash
cd backend
pip install -r requirements.txt

# (optional) regenerate data + retrain
python training/build_dataset.py
python training/train.py

# run the API
python app.py          # http://localhost:8000  (docs at /docs)
```

`ffmpeg` is recommended for `/api/analyze-audio` (decoding mp3/m4a); WAV works
without it.

## Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Service + model status |
| GET | `/api/styles` | All dance styles grouped by category |
| GET | `/api/metadata` | Full training/model metadata |
| POST | `/api/predict` | Predict from a song title/artist/genre |
| POST | `/api/predict-features` | Predict from an explicit feature dict |
| POST | `/api/analyze-audio` | Upload an audio file, extract features, predict |

### Example

```bash
curl -X POST http://localhost:8000/api/predict \
  -H 'Content-Type: application/json' \
  -d '{"title":"Shape of You","artist":"Ed Sheeran","genre":"pop"}'
```

## Notes

- The corpus is *seeded* from musical priors rather than labelled audio. For
  production-grade accuracy, replace `data/song_corpus.csv` with measured audio
  features (e.g. from the GTZAN / FMA datasets with dance-style labels) and
  re-run `training/train.py`. The training script and API do not need changes.
- Audio feature extraction uses only `numpy`/`scipy` (+ `ffmpeg` for decoding),
  so it runs on a minimal dependency stack.
